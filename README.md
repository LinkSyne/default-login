# default

Небольшое окно входа для Windows в тёмном минималистичном стиле. Написано на C++ с использованием Dear ImGui и Direct3D 11, поставляется одним исполняемым файлом.

> [!CAUTION]
> Данные для входа вшиты в исполняемый файл в открытом виде и не являются защитой. Не используйте их для реальной авторизации без собственной серверной проверки.

## Возможности

* окно без рамки со скруглёнными углами;
* анимированные поля ввода и подсветка активного поля;
* анимация ошибки при неверных данных;
* анимированная заставка при входе;
* поддержка высокого DPI и масштабирование интерфейса;
* перемещение окна за любую свободную область;
* шрифты встроены в программу.

## Использование

> [!IMPORTANT]
> Для корректной работы на компьютере должны быть установлены:
>
> * [Microsoft Visual C++ Redistributable 2015-2022 (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)
> * [DirectX End-User Runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35)

1. Распаковать архив в любую папку.
2. Запустить исполняемый файл.
3. Ввести данные для входа и нажать **Sign In** или Enter.

Данные по умолчанию:

| Поле     | Значение |
|----------|----------|
| Email    | default  |
| Password | default  |

Файлы `icon.png` и `avatar.png`, лежащие рядом с исполняемым файлом, необязательны. Первый отображается справа, второй используется как логотип над формой. Без них рисуются встроенные заглушки.

Закрыть окно можно кнопкой в правом верхнем углу или клавишей Escape.

## Разработчикам

> [!WARNING]
> Для самостоятельной сборки требуется Visual Studio 2019 или новее и компилятор с поддержкой C++17.

Проект состоит из одного файла `release.cpp`. Для сборки нужен [Dear ImGui](https://github.com/ocornut/imgui) с бэкендами Win32 и DirectX 11.

1. Создать пустой проект Win32 C++ в Visual Studio.
2. Добавить `release.cpp` и исходники ImGui:
   * `imgui.cpp`, `imgui_draw.cpp`, `imgui_tables.cpp`, `imgui_widgets.cpp`
   * `backends/imgui_impl_win32.cpp`
   * `backends/imgui_impl_dx11.cpp`
3. Указать пути к папке ImGui и к `backends` в каталогах включения.
4. Выставить подсистему Windows (`/SUBSYSTEM:WINDOWS`) и стандарт C++17.
5. Собрать в конфигурации Release x64.

Логин, пароль, заголовок окна и тексты находятся в начале соответствующих функций в `release.cpp`.
